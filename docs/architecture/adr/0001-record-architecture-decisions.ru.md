# ADR-0001: Фиксация архитектурных решений

- Статус: Принято
- Дата: 2026-10-06
- Язык: [English](0001-record-architecture-decisions.md) · Русский

## Контекст

Продуктовая спецификация требует вести записи об архитектурных решениях (промпт §101) и журнал решений (`docs/DECISIONS.md`, промпт §112). Платформа будет развиваться на протяжении многих фаз. Участникам разработки и владельцу нужно понимать, почему всё устроено именно так, какие альтернативы были отклонены и когда решение можно пересмотреть.

## Решение

- Каждое архитектурно значимое решение фиксируется в виде ADR в `docs/architecture/adr/NNNN-short-title.md` на английском языке, а рядом лежит русский перевод `NNNN-short-title.ru.md`.
- Формат: облегчённый вариант MADR со следующими разделами: Статус, Дата, Контекст, Решение, Рассмотренные альтернативы, Последствия, Ссылки.
- Статусы: `Proposed` → `Accepted` → (`Deprecated` | `Superseded by ADR-XXXX`). После принятия ADR не изменяется. Если решение пересматривается, пишется новый ADR, который заменяет старый.
- `docs/DECISIONS.md` служит указателем: по одной строке на каждый ADR с названием, статусом и кратким описанием в одно предложение.
- ADR обязателен, если изменение затрагивает границы модулей, публичные интерфейсы (`pkg/sdk`, `pkg/spec`, API), хранение данных, модель безопасности, набор зависимостей, лицензирование или матрицу поддерживаемых версий.
- ADR Фазы 0 остаются в статусе `Proposed`, пока владелец не утвердит архитектуру. После этого они одним коммитом переводятся в статус `Accepted`.

## Рассмотренные альтернативы

- **Без ADR, только проектные документы.** Обоснования теряются в больших документах, и трудно увидеть, какие соображения уже устарели.
- **Полный шаблон MADR.** Слишком тяжеловесен для такого объёма решений. Облегчённый вариант сохраняет ключевые поля.

## Последствия

- Плюсы: решения прослеживаемы, их можно рецензировать и ссылаться на них из код-ревью и документации.
- Минусы: каждое решение требует дополнительных усилий на описание, а два языка удваивают эти затраты. Это приемлемо, поскольку владелец работает на русском.
